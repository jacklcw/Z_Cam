0.107.2
- What's new now lists every version (it had stopped at 0.104.1).

0.107.1
- New switch: Window animations (floating windows settings). Off makes every floating window cut in and out with no fade or animation.

0.107.0
- New: heartbeat. Z_Cam logs a beat every minute and sends them to your relay, so ZDash can show whether Z_Cam is still running (needs a linked relay; without one it only writes locally).
- Minimised window dock can be dragged: near the left or right edge it snaps and stacks vertically, near the top it stays where you put it.
- Trip widget: the hide, pencil and pin buttons only show for a few seconds after you tap the widget, so they no longer cover the content.
- Trip widget Full: chart beside the speed with a taller top section, shorter tiles with larger text, and a square-ish box keeps the Full layout.
- Layout sets now also save the trip widget (detail, orientation, chart, tiles, size). Switching layout brings back every minimised window.
- Long press a layout set to move it up or down; the floating arc follows the same order.

0.106.0
- The minimised window dock can be dragged out of the way. Drop it near the left or right edge and it snaps there and stacks vertically.
- Trip widget: when you resize it to a square, the small tiles move to the bottom under the chart.

0.105.1
- New: leave-car trigger. When both front seats are empty, the gear is P and the car reads locked, Z_Cam tells your relay so Auto Sentry and the other automations run within seconds instead of at the next 5-minute check. Needs a linked relay; without one nothing is sent.
- The ping retries when the car internet is still reconnecting, and the Z_Cam log shows left: ping sent or failed.

0.104.1
- Credits screen now opens with the required Zeekr Shortcut attribution line.
- Added the GPL-3.0 LICENSE file and the missing source header on the Civic Type R voice.

0.104.0
- Lane keep assist per driving profile: pick Keep / On / Off for each drive mode in Driving profiles; it is set along with steering and regen when the mode applies.
- Hold the floating button, hover a drive mode: a new arc beyond steering and regen sets its lane keep assist (On / Off, tap again = keep).
- The floating ring sector formerly called Acceleration mode is now Driving profile.
- The sector name now shows just above the ring so it is not missed.

0.103.0
- Distance guide lines on the left and right floating cameras: tap the new guide button in the window header, drag to draw a line, spread two fingers to copy it into up to 4 parallel lines with a red shade between them. Drag the dots to set the angle and each line's length (a farther line is never longer than a closer one). Clear and Hide buttons appear while editing. The same lines show on the HUD picture. They are a rough visual reference only: always judge the real situation yourself.
- The minimize button looks disabled while a window is pinned.
- Window corners resize reliably even when windows overlap, with a larger touch area.

0.102.0
- Layout sets: from the Layout sets button in the left column, save the HUD and floating window layout as a named set, switch between sets, copy a set, rename, update or delete it. A set also remembers which floating windows are on. Each set shows when it was created and last edited. Hold the floating button and hover Layout sets to switch set right from the arc.
- Floating web window: drag any corner to resize it freely, width and height separately (the HUD picture takes the same shape).
- The web window pin button now sits in the same place as on the other windows.
- Apply default settings has been refreshed and keeps your saved layout sets.

0.101.0
- Pin button in every floating window header (cameras, web, trip): a pinned window stays when you minimize everything with the floating button.
- The floating button now shows whenever its switch is on, even with no floating window turned on, and starts at boot.

0.100.0
- Floating arc: hover an acceleration mode to set its steering (Light, Standard, Heavy) and regeneration (Standard, Strong) right on the arc. Tap the chosen option again to leave the car as is.

0.99.4
- Speed limit: the glow and beep only trigger once you are a whole km/h over the limit, so driving at 60 in a 60 zone no longer alerts.

0.99.3
- Credits: now shows the GPL-3.0 license notice, no warranty, the Zeekr Shortcut code credit and the source link; the engine sound is credited as dts88's original work.
- Log: keeps more lines (4000) for relay upload, and the speed debug log adds a 10 s heartbeat away from the limit.

0.99.2
- Speed limit: new debug switch that logs your driving speed (car sensor or GPS) near the limit to the log, so the glow can be compared with the real speed.

0.99.1
- Pairing: new Change relay button on the Cameras and pairing code screens, so you can point the car at a different relay (clears the relay and link and shows the setup QR again).

0.99.0
- Zed no longer walks onto the system status bar (his area now stops at the bars), so you cannot tap him there.
- Reports whether a front seat is occupied and whether the gear is in P to the relay (used by ZDash Auto-lock).
- Shows the Camping reminder and Auto-lock on hold alerts in the car notification pane (needs ZDash with a relay).

0.98.0
- Speed limit sign: new sliders to adjust the red border thickness and the number size (included in settings backup).

0.97.0
- Zed has a natural body-shaped shadow (soft drop shadow plus a thin dark contour) so he stays visible on any background.
- Zed now spends little time on the right 30% of the screen, where the steering wheel hides it: he mostly walks, hops, hangs and climbs on the left.
- Zed is round when rested and gets slimmer the more you drive today (60 km is fully fit). At midnight he smoothly returns to his round body.
